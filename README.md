# SRE Automation Lab

A hands-on SRE portfolio focused on reproducible engineering, operational evidence and explainable trade-offs.

## Projects
- [Project 01: SLO-Driven Microservice Reliability](projects/01-slo-microservice/README.md)

## Portfolio principles
- Reproducible over screenshot-only demos.
- Measure before making reliability claims.
- Prefer user-visible symptoms over noisy cause-only alerts.
- Document trade-offs, failure modes and recovery evidence.
- Never commit credentials, tokens or production secrets.
